Une flotte, plusieurs agences, aucune double réservation.

FleetDesk réunit réservations, contrats, facturation, maintenance et prévision de la demande pour une société de location de véhicules. La règle « un véhicule ne peut pas être loué deux fois sur la même période » est garantie par la base de données, pas seulement par l'écran.

Ce que fait l'application

Tableau de bord
Taux d'occupation, chiffre d'affaires du mois, retours du jour, véhicules en maintenance, courbe réel / prévu.
Flotte et clients
Fiches véhicules et clients, statuts, kilométrage, historique des locations et des interventions.
Réservations
Calendrier par véhicule mis à jour en direct, création en un clic, conflits refusés par la base.
Contrats
Création depuis une réservation, signature horodatée, états des lieux départ et retour avec photos.
Facturation
Facture et PDF générés à la clôture du contrat, paiements partiels, retards, relances par e-mail.
Maintenance
Planification et alertes kilométriques ; un véhicule immobilisé ne peut plus être réservé sur la période.
Assistant IA
Questions en langage naturel, brouillons de réservation à valider, prévision de la demande, aide au contrôle des dommages. Optionnel.
Paramètres
Agences, tarifs par catégorie, utilisateurs, rôles et invitations.

Comment c'est construit

Navigateur ── Next.js (Vercel) ──────────────┐
                 │ JWT utilisateur            │
                 ▼                            ▼
          Supabase : Postgres + RLS    billing-service (Render)
          Auth · Storage · Realtime     PDF · e-mails · relances
                 ▲                            │ clé service_role
   Edge Functions (Gemini) ◄── pg_cron        ▼
   assistant · prévision · dommages        factures, PDF dans Storage

Toute la sécurité repose sur la base : Row Level Security sur chaque table, un client ne voit jamais les données d'une autre société, et les rôles sont appliqués par PostgreSQL. Aucun secret n'est dans le dépôt ; aucun Docker n'est nécessaire.

Lancer le projet

git clone {{REPO_URL}}.git && cd fleetdesk
# 1. Supabase : exécuter supabase/migrations/0001 → 0008 dans le SQL Editor
# 2. Application
cd web && npm install && copy .env.example .env.local && npm run dev
# 3. Service de facturation
cd billing-service && npm install && copy .env.example .env && npm run dev
